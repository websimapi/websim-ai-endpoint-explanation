Understanding the AI Endpoint

How the AI Endpoint Works

The websim.chat.completions.create function is your primary way to interact with the language model (AI). It's designed to be straightforward:

  • websim.chat.completions.create({}): This is the core function call. You pass an object to it containing your request parameters.
  • messages: []: This is the most important parameter. It's an array of message objects that form the conversation history. The AI uses this history to understand the context of the current request.
  • Message Object Structure: Each message object in the messages array must have a role and content:
    • role: "system": An optional message that sets the behavior or persona of the AI. This is usually the first message in the array.
    • role: "user": The prompt or question from the user.
    • role: "assistant": (Not typically sent by you in the request, but often added to history after the AI responds) The AI's previous responses.
  • content: "Your text here": The actual text of the message.
  • json: true: (Optional) If you want the AI to respond with a structured JSON object, set this to true and ensure your system message guides the AI to output valid JSON following a schema you provide.

When you call create, the AI processes the messages array and generates a response based on the conversation context and its training. The response's content will be available in completion.content.
